# Movie Ticket Booking System

CSE 2102 – Data Structures project (B.Tech Cyber Security, B.S. Abdur Rahman Crescent Institute of Science & Technology).

Booking requests wait in a **queue** (first in, first out). Confirmed bookings are stored on a **stack**, so the latest booking is the first one that can be cancelled.

## Files

- `index.html` – interactive website (open it in any browser, no install needed)
- `movie_booking.c` – the original console program written in C

## Run the C program

```
gcc movie_booking.c -o movie_booking
./movie_booking
```
